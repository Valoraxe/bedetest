- Basic React-Native application using Expo and TypeScript
- I couldn't find the API call to the games website, so had to create my own JSON file to house the data in assets/data.json
- Decided to use navigation parameters instead of Context API and other global state packages to keep it basic
- Did not have time to add filter and search functionality (specially for longer lists)
- Tested on iPhone Pro 16 (iOS 18.4) and Medium Phone API 36 (Android 16) simulators

# INSTALLATION

- Make sure your node version is on Krypton (v24.21.0)
- Use git clone to get the repo onto your local machine
- Open Terminal, navigate to the project repo, and use npm install or yarn install
- Run the app with yarn android, or npm run android (you can use ios as well)
- Have fun!
